# GDRL — Graph Distillation for Low-Resource Relational Learning

Official code for the paper **Graph Distillation for Low-Resource Relational Learning**
(Harborlight Research Lab, P-2202).

## Status

**Status: Released** — v1.0.4 (public). This folder contains the code
used for the experiments reported in the paper.

## Layout

- `src/` — model and data pipeline
- `experiments/` — training and evaluation entry points
- `notebooks/` — analysis notebooks
- `results/` — reported numbers
- `tests/` — smoke tests
